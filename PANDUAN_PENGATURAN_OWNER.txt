📌 ATURAN EMAS SAAT MENGEDIT FILE (PENTING DIBACA DULU):
--------------------------------------------------------------------------------
1. Anda cukup menggunakan aplikasi "Notepad" bawaan Windows atau "Notepad++".
   Cara buka: Klik kanan file config.js -> Pilih "Open with" -> Pilih "Notepad".
2. JANGAN MENGHAPUS tanda petik (" "), tanda koma (,), atau kurung kurawal ({ }).
3. Tulis teks Anda di antara tanda petik, contoh: name: "NAMA HOTSPOT ANDA"
4. Untuk HARGA, tulis angka murni tanpa titik/koma, contoh: price: 8000 (bukan 8.000)
5. Jangan lupa simpan perubahan: Tekan tombol Ctrl + S di keyboard.

LANGKAH 2: MENGUBAH HARGA & DAFTAR PAKET INTERNET
================================================================================
Cari bagian "packages: [" di file config.js.
Di bawahnya terdapat daftar paket voucher Anda.

Contoh 1 Paket Voucher:
    {
      id: "pkt_1",
      name: "Paket Merdeka 2 Jam",
      duration: "2 Jam",
      speed: "Up to 5 Mbps",
      quota: "Unlimited FUP",
      price: 2000,
      popular: false,
      badge: "Hemat"
    },

Penjelasan Setiap Baris:
• "name"     : Nama paket yang tampil di kartu (misal: "Paket Pelajar 2 Jam")
• "duration" : Durasi waktu pakai (misal: "2 Jam" atau "1 Hari")
• "speed"    : Keterangan kecepatan (misal: "Up to 5 Mbps")
• "quota"    : Keterangan kuota (misal: "Unlimited" atau "Kuota 2 GB")
• "price"    : Harga dalam rupiah. Cukup tulis angkanya saja!
               Contoh: 2000 (Otomatis tampil sebagai Rp 2.000 di web)
• "popular"  : Tulis true jika ingin paket ini diberi garis merah "Paling Laris"
               Tulis false jika paket biasa.
• "badge"    : Label tulisan kecil di pojok paket (misal: "Hemat" / "Promo")

LANGKAH 3: MENGUBAH LOKASI WARUNG / AGEN PENJUAL VOUCHER
================================================================================
Cari bagian "outlets: [" di file config.js.
Anda bisa menyesuaikan nama warung/konter mitra tempat beli voucher.

Contoh 1 Lokasi Agen:
    {
      name: "Warung Berkah Bu Siti",
      address: "Jl. Mawar No. 12 (Depan Lapangan)",
      hours: "07:00 - 22:00 WIB",
      status: "Buka"
    },

Penjelasan:
• "name"    : Nama toko / warung mitra Anda
• "address" : Alamat atau patokan lokasi warung
• "hours"   : Jam buka toko (misal: "07:00 - 22:00 WIB" atau "Buka 24 Jam")
• "status"  : Tulis "Buka" atau "Tutup"

LANGKAH 4: MENGUBAH TANYA JAWAB BANTUAN (FAQ)
================================================================================
Cari bagian "faqs: [" di file config.js.
Bagian ini mengatur jawaban otomatis saat pelanggan membuka menu Bantuan.

Contoh 1 Tanya Jawab:
    {
      q: "Bagaimana cara login menggunakan Voucher?",
      a: "Pilih tab 'Login', masukkan Kode Voucher ke kolom, lalu klik tombol 'Masuk'."
    },

• "q" : Pertanyaan yang sering ditanyakan pelanggan
• "a" : Jawaban petunjuk dari Anda

LANGKAH 7: MENERAPKAN PERUBAHAN KE ROUTER MIKROTIK
================================================================================
Setelah Anda selesai mengedit file config.js dan menyimpannya (Ctrl + S):

1. Buka aplikasi Winbox di laptop/komputer Anda dan login ke MikroTik.
2. Klik menu "Files" di sebelah kiri Winbox.
3. Buka folder template Anda di komputer.
4. Tarik (Drag & Drop) file "config.js" yang baru Anda edit ke dalam folder 
   template di jendela Files Winbox (misal ke dalam folder: maleo-hotspot/js/).
5. Selesai! Perubahan harga, nama, dan teks langsung aktif seketika di Wi-Fi Anda.
